# Group Policy Basics

## Overview

This document explains the use of Group Policy Objects (GPOs) in the Enterprise IT Home Lab.

## Objectives

Learn how to:

- Create GPOs
- Link GPOs to Organizational Units
- Configure password policies
- Configure desktop settings
- Configure security settings

## Planned Policies

- Password complexity
- Account lockout
- Desktop wallpaper
- Windows Updates
- Control Panel restrictions

## Skills Demonstrated

- Active Directory
- Group Policy Management
- Windows Administration
